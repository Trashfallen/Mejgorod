# MihomoDesk

[English version](README.md)

VPN-клиент для Windows на ядре [mihomo](https://github.com/MetaCubeX/mihomo) с управлением одной кнопкой. Вставьте тот же конфиг, что в XKeen на роутере, нажмите кнопку питания, и весь трафик ПК пойдёт через mihomo в режиме TUN. Живёт в трее.

## Возможности

- **Одна кнопка.** Подключение и отключение с главного экрана или из значка в трее. На главной ещё выбор сервера (с пунктом «Добавить сервер») и выбор профиля.
- **Профили.** Несколько конфигов рядом: свой, «Всё через VPN», «Выборочно» и т.д. Шаблон при выборе становится профилем и дальше правится как свой. Управление профилями - на вкладке «Конфиг».
- **Конфиг роутера как есть.** Конфиг XKeen адаптируется под ПК на лету, ваш текст не переписывается.
- **Шаблоны.** Редактор по умолчанию пустой. Кнопка «Шаблон» загружает встроенный конфиг или любой `.yaml` из папки `templates` рядом с exe.
- **Серверы.** Импорт ссылок `vless://` (ссылка подхватывается из буфера обмена) и переключение между ними. Первый импортированный сервер выбирается сам. Шестерёнка открывает параметры сервера в YAML (SNI, fingerprint, flow, транспорт и т.д.), ядро проверяет их перед сохранением.
- **Доска групп.** Две колонки: «Через VPN» и «Напрямую». Сервис (YouTube, Discord и т.д.) перетаскивается между ними, по клику можно выбрать конкретный сервер. Работает и без подключения: выбор применится при подключении.
- **Свои сайты и программы.** Кнопка «+» в колонке добавляет сайт или программу. Домены сайта программа ищет в списках geosite/geoip от MetaCubeX (instagram.com -> 74 домена, список обновляется сам). У программы весь трафик идёт выбранным путём (`PROCESS-NAME`).
- **Логи и проверки.** Логи ядра с фильтрами. Конфиг перед запуском проверяет ядро, по ошибке можно перейти к строке в редакторе.
- **Работает рядом с Citrix.** Уживается с Citrix Secure Access (см. ниже).
- **Обновления.** При запуске программа смотрит релизы этого репозитория. Кнопка «Обновить» скачивает новый exe, подменяет его и перезапускает программу без запроса UAC, окно остаётся открытым.
- **Лёгкая.** Свёрнутое окно почти не опрашивает программу. Конфиг перечитывается, только когда изменился, список соединений запрашивается у ядра, только пока окно открыто.
- **Переносная.** Всё хранится рядом с exe. Ядро mihomo скачивается с официальных релизов при первом подключении.

## Требования

- Windows 10 или 11, x64.
- Права администратора: без них TUN не создать. Программа сама запрашивает их при запуске.

## Как начать

1. Соберите программу (см. [Сборка](#сборка)) или возьмите `MihomoDesk.exe` на странице Releases, если он там есть.
2. Положите `MihomoDesk.exe` в любую папку и запустите. Данные хранятся в `data` рядом с exe.
3. На вкладке «Конфиг» вставьте свой конфиг или загрузите шаблон.
4. Если в конфиге нет серверов, импортируйте ссылку `vless://` на вкладке «Серверы».
5. Нажмите кнопку питания.

Закрытие окна сворачивает программу в трей, VPN продолжает работать. Выход: меню значка в трее или «Настройки» -> «Выйти».

## Шаблоны

- **Выборочно через VPN** (встроенный): заблокированные сервисы и группы сервисов идут через VPN, остальное `MATCH,DIRECT`.
- **Всё через VPN, российское напрямую** (встроенный): группа PROXY, `MATCH,PROXY`.
- Любой `.yaml` из папки `templates` рядом с exe.

Серверов в шаблонах нет. Свой конфиг с UUID держите в `templates`, а не встраивайте в exe, и не отдавайте эту папку другим.

## Что программа делает с конфигом

Конфиг активного профиля хранится как вставлен (`data\profiles\<имя>.yaml`). Перед запуском ядра программа собирает из него версию для ПК (`data\home\config.yaml`):

- комментирует настройки роутера: `redir-port`, `tproxy-port`, `routing-mark`, `interface-name`;
- `allow-lan: false`, `external-controller: 127.0.0.1:<порт>`;
- `find-process-mode: off` -> `strict`, чтобы работали правила `PROCESS-NAME`;
- убирает `listen` из `dns` и добавляет блок `tun`;
- если у ПК нет IPv6, ставит `ipv6: false`;
- исключает адреса серверов из TUN (`route-exclude-address`);
- серверы с вкладки «Серверы» добавляет inline-провайдером `mihomodesk`, их видят группы с `include-all: true`.

Убранные строки комментируются, а не удаляются, поэтому номера строк в ошибках ядра совпадают с редактором.

Сайты и программы, добавленные кнопкой «+», пишутся прямо в конфиг, так что он работает и на роутере:

```yaml
rules:
  # MihomoDesk: свои сайты и программы (вкладка «Группы»)
  - OR,((DOMAIN-SUFFIX,instagram.com),(RULE-SET,instagram@domain)),PROXY # desk: instagram.com
  - PROCESS-NAME,Telegram.exe,DIRECT # desk: Telegram.exe
  # MihomoDesk: конец
```

Раздел стоит первым в `rules`: явный выбор важнее остальных правил. Найденные для сайтов списки попадают в такой же раздел в конце `rule-providers`. Строки между метками руками не правьте: вкладка «Группы» их перезаписывает.

## Рядом с Citrix Secure Access

Citrix перехватывает исходящие пакеты, «не свои» возвращает в стек Windows и сбрасывает соединения, которые ему не нравятся. Обычный TUN с маршрутом по умолчанию с ним не уживается. Ядро ловит собственные соединения (тысячи `reject loopback`, компьютер тормозит), а Citrix прокладывает маршрут к своему шлюзу через TUN и рвётся сам.

Пока Citrix подключён, режим маршрутов «Авто» (Настройки -> TUN -> Маршруты) включает совместимость:

- DNS отдаёт приложениям адреса fake-ip. В TUN идут только они и подсети из правил с `no-resolve`, которые ведут в VPN (например, OVH для игровых серверов, Telegram, Meta). Остальное, включая соединения самого ядра, идёт мимо TUN;
- внутренние домены Citrix (список поиска DNS) получают настоящие адреса от его DNS;
- шлюз Citrix и серверы исключены из TUN;
- стек TUN принудительно gvisor: пакеты стеков system и mixed Citrix сбрасывает.

Если Citrix подключили или отключили при работающем VPN, программа переподключится сама. Если петля всё же случится, VPN отключится сам через несколько секунд, а вывод лога ядра ограничен 100 строками в секунду.

## Сборка

Нужен Go 1.25+.

```
build.cmd
```

Скрипт встраивает иконку и версию и собирает `dist\MihomoDesk.exe`.

Отладка интерфейса без прав администратора и без TUN:

```
set MIHOMODESK_DEV_NOTUN=1
dist\MihomoDesk.exe --no-elevate
```

Тесты: `go test ./...`. Проверка реального конфига ядром:

```
set MIHOMODESK_CONFIG=путь\к\config.yaml
set MIHOMODESK_CORE=dist\data\core\mihomo.exe
go test -run TestAdaptRealConfig -v .
```

## Релизы

Программа обновляется из последнего релиза этого репозитория:

1. Поднимите `appVersion` в `main.go` и версию в `build.cmd`, соберите `build.cmd`.
2. Создайте релиз с тегом вида `v1.2.0` и прикрепите `dist\MihomoDesk.exe`. Файл должен называться ровно `MihomoDesk.exe`.

Программы со старой версией предложат обновиться при следующем запуске.
